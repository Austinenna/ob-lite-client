# OB Lite Client 功能需求文档

日期：2026-06-05

## 1. 产品目标

做一个 macOS 上的极简轻量数据库客户端，专门用于连接 OceanBase MySQL 模式。

第一版只解决两个核心问题：

- 查看数据库、表、字段和表数据。
- 编写并执行 SQL，查看执行结果和错误信息。

不做大而全的数据库管理工具，不追求替代 Navicat、DataGrip 的所有能力。

## 2. 技术范围

- 前端：React
- 桌面容器：Tauri
- 后端：Rust
- 数据库协议：MySQL 协议
- 目标数据库：OceanBase MySQL 模式
- 运行平台：macOS

## 3. MVP 必做功能

### 3.1 连接管理

用户可以新增、编辑、删除、测试 OceanBase 连接。

必需字段：

- 连接名称
- Host
- Port
- Username
- Password
- Database，可为空

连接能力：

- 测试连接
- 保存连接
- 删除连接
- 打开连接
- 断开连接
- 显示连接状态

安全要求：

- 密码不明文展示。
- 密码不明文保存在普通配置文件中。
- 优先使用 macOS Keychain 保存密码。

### 3.2 数据库与表浏览

连接成功后，用户可以浏览当前连接下的数据库对象。

必做能力：

- 查看数据库列表
- 查看某个数据库下的表列表
- 查看某张表的字段列表
- 查看字段类型
- 查看字段是否可为空
- 查看字段默认值
- 查看主键信息
- 手动刷新数据库对象

元数据查询要求：

- 不一次性拉取所有库、所有表、所有字段。
- 用户展开某个节点时再加载对应数据。
- 已加载的库、表、字段需要缓存。
- 支持手动刷新缓存。

### 3.3 表数据查看

用户点击表名后，可以查看该表的数据。

必做能力：

- 默认查询前 200 行
- 支持分页
- 支持切换每页行数
- 支持刷新当前表数据
- 支持查看完整单元格内容
- 支持复制单元格内容
- 支持复制整行数据

分页要求：

- 默认每页 200 行。
- 可选每页 100、200、500、1000 行。
- 有主键时优先使用主键分页。
- 无主键时使用 LIMIT/OFFSET 分页。
- 不默认执行 COUNT(*)。

数据展示要求：

- NULL 值需要明确显示。
- 超长文本默认截断。
- 二进制字段需要特殊标记，不直接完整渲染。
- 时间、数字、字符串按原始查询结果展示，不强行格式化。

### 3.4 SQL 编辑与执行

用户可以输入 SQL 并执行。

必做能力：

- 输入 SQL
- 执行当前 SQL
- 执行选中的 SQL
- 清空 SQL
- 取消正在执行的 SQL
- 展示 SQL 执行状态
- 展示 SQL 执行耗时
- 展示返回行数或影响行数
- 展示 SQL 错误信息

快捷键：

- Cmd + Enter：执行 SQL
- Esc：取消正在执行的 SQL

执行规则：

- SELECT、SHOW、DESC、EXPLAIN 等查询语句展示结果表格。
- INSERT、UPDATE、DELETE、DDL 等语句展示影响行数或执行结果。
- 单次执行可以先只支持一条 SQL。
- 多语句执行可放到后续版本。

安全与稳定要求：

- SQL 执行必须异步，不阻塞界面。
- 查询必须支持超时。
- 长时间查询必须支持取消。
- 执行错误不能导致应用崩溃。

### 3.5 查询结果

SQL 执行完成后，用户可以查看结果。

必做能力：

- 展示结果表格
- 展示列名
- 展示字段值
- 复制单元格
- 复制行
- 复制全部结果，可限制最大复制行数
- 清空结果

结果状态：

- 未执行
- 执行中
- 执行成功，有结果
- 执行成功，无结果
- 执行失败
- 查询超时
- 查询已取消

性能要求：

- 结果表格必须支持虚拟滚动。
- 不一次性渲染大量 DOM 行。
- 大结果集需要分批传输或限制返回量。
- 默认查询结果限制为 1000 行以内，可配置。

### 3.6 错误处理

应用需要对常见错误给出可读提示。

必做错误类型：

- Host 不可达
- 端口不可达
- 用户名或密码错误
- 数据库不存在
- 权限不足
- SQL 语法错误
- 查询超时
- 连接断开
- OceanBase 租户或账号格式错误

错误展示要求：

- 展示原始错误信息。
- 展示简短中文说明。
- 不使用整屏阻断式弹窗展示普通 SQL 错误。

### 3.7 状态与日志

应用需要展示基础运行状态，便于用户判断当前情况。

必做状态：

- 当前连接名称
- 当前数据库
- 是否已连接
- SQL 是否执行中
- 最近一次执行耗时
- 最近一次返回行数
- 最近一次错误

基础日志：

- 记录连接成功/失败
- 记录 SQL 执行开始/结束
- 记录 SQL 执行耗时
- 记录错误信息

日志只用于本地排查，不上传。

## 4. 第一版建议包含的增强功能

这些功能不是最低可用要求，但建议第一版一起做，能显著提升使用体验。

### 4.1 查询历史

- 自动记录最近执行的 SQL
- 展示执行时间
- 展示执行连接
- 展示执行耗时
- 支持一键重新填入编辑器
- 支持清空历史

### 4.2 SQL 收藏

- 收藏常用 SQL
- 取消收藏
- 给收藏 SQL 命名
- 从收藏中恢复到编辑器

### 4.3 表结构详情

- 查看字段列表
- 查看索引列表
- 查看建表语句
- 复制建表语句

### 4.4 EXPLAIN

- 对当前 SQL 执行 EXPLAIN
- 展示 EXPLAIN 结果表格
- 不做复杂性能分析，只展示数据库返回结果

## 5. 后续版本功能

以下功能可以放到 V0.2 或 V0.3。

### 5.1 多连接

- 同时打开多个连接
- 每个连接独立状态
- 每个连接独立 SQL 历史

### 5.2 多结果集

- 支持执行多条 SQL
- 每条 SQL 独立结果
- 支持在多个结果之间切换

### 5.3 数据导出

- 导出当前结果为 CSV
- 导出当前结果为 JSON
- 导出前限制最大行数

### 5.4 数据编辑

- 编辑单元格
- 新增行
- 删除行
- 提交修改
- 回滚未提交修改

数据编辑风险较高，不建议放入 MVP。

### 5.5 连接分组

- 给连接分组
- 按环境区分连接，例如开发、测试、生产
- 支持连接搜索

### 5.6 只读模式

- 连接级只读开关
- 只读模式下禁止 INSERT、UPDATE、DELETE、DDL
- 生产环境连接默认建议只读

## 6. 明确暂不做的功能

MVP 不做以下能力：

- 图形化建表
- 图形化改表
- ER 图
- 数据库备份
- 数据库恢复
- 用户权限管理
- 存储过程编辑
- 触发器编辑
- 复杂 SQL 自动补全
- AI 写 SQL
- 云同步
- 团队协作
- 远程分享查询结果
- 替代完整 DBA 工具

## 7. 性能要求

### 7.1 数据加载

- 表数据默认最多加载 200 行。
- SQL 查询默认最多返回 1000 行。
- 所有大数据查询都必须有限制。
- 禁止默认全表扫描大表。
- 禁止默认 COUNT(*) 大表。

### 7.2 界面性能

- 表格必须虚拟滚动。
- 大结果集不能导致界面卡死。
- SQL 执行不能阻塞主线程。
- 拖动、滚动、切换表时应保持响应。

### 7.3 后端性能

- 使用连接池。
- 连接池大小可配置。
- 查询设置超时时间。
- 查询结果分批返回。
- 大字段限制单元格展示长度。

### 7.4 默认配置

- 表数据每页行数：200
- SQL 最大返回行数：1000
- 查询超时：30 秒
- 连接超时：10 秒
- 单元格预览最大长度：200 字符
- 查询历史最大条数：200

## 8. OceanBase MySQL 模式适配要求

### 8.1 连接格式

需要支持 OceanBase MySQL 模式常见账号格式。

示例：

- username
- username@tenant
- username@tenant#cluster

具体格式不在前端强制限制，由后端连接测试返回结果。

### 8.2 元数据 SQL

需要支持以下基础元数据查询：

```sql
SHOW DATABASES;
SHOW TABLES;
SHOW FULL COLUMNS FROM `table_name`;
SHOW INDEX FROM `table_name`;
SHOW CREATE TABLE `table_name`;
```

### 8.3 会话参数

连接成功后建议设置：

```sql
SET NAMES utf8mb4;
```

如 OceanBase 环境支持查询超时参数，可在后端做连接级或语句级超时控制。

- name
- host
- port
- username
- database
- sslEnabled

- updatedAt

密码单独存储，不进入普通连接配置。

### 9.2 DatabaseObject

- connectionId
- databaseName
- tableName
- objectType

objectType 可选：

- database
- table
- view

### 9.3 Column

- databaseName
- tableName
- columnName
- dataType
- nullable
- defaultValue
- isPrimaryKey
- ordinalPosition

### 9.4 QueryExecution

- id
- connectionId
- databaseName
- sql
- status
- startedAt
- finishedAt
- durationMs
- rowCount
- affectedRows
- errorMessage

## 10. 验收标准

MVP 达到以下标准即可认为可用：

- 可以保存并打开 OceanBase MySQL 模式连接。
- 可以看到数据库列表。
- 可以看到表列表。
- 可以看到表字段。
- 点击表可以分页查看数据。
- 可以输入并执行 SELECT SQL。
- 可以输入并执行非 SELECT SQL。
- 可以看到查询结果。
- 可以看到影响行数。
- 可以看到 SQL 错误。
- 查询执行过程中界面不卡死。
- 大表不会被默认全量加载。
- 密码不会明文保存在普通文件中。

- 查询结果展示
- 错误处理
- 查询超时

- 查询历史
- 表结构详情

- 多连接
- 多结果集
- CSV/JSON 导出
- SQL 收藏
- 只读模式
- 连接分组

P3 暂不做：

- 数据编辑
- ER 图
- 图形化建表/改表
- AI 写 SQL
- 云同步
